# Assets

All in-game art and audio are **procedural** — no third-party sprite or sound packs.

| Asset | Source | Notes |
| --- | --- | --- |
| Map tiles, biomes, towers, enemies, VFX | Canvas 2D in `src/game/render/` | Gradients, shapes, seeded texture |
| Sound effects | Web Audio synth in `src/game/audio.ts` | Mute persists in localStorage |
| Fonts: Syne + DM Sans | Google Fonts | SIL Open Font License |
| Favicon | Inline SVG in `index.html` | Original |

No AI-generated image files and no paid asset packs were used for this build.
